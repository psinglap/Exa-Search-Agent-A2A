1What an Agent Card is, and why this is positioning

A public business card for an agent: what it does, how to call it, how to pay.

In A2A (Agent2Agent, the open protocol Google started and the Linux Foundation now runs; 150+ organizations), an agent publishes an Agent Card: a JSON file at /.well-known/agent-card.json that tells other agents its skills, endpoint and sign-in method. A calling agent reads the card, sends a task, and gets a result back. Exa already ships every part except the card itself.

3Example use case: a sales agent hires Exa

A CRM's sales agent needs a target list. It hires Exa for one task.

A sales agent running on any A2A platform (Gemini Enterprise, Salesforce Agentforce, AWS AgentCore) is asked for "EU fintechs that launched an AI agent this year". Rather than running dozens of searches and reading every page itself, it hires Exa. The company data below is made up.

1

Discover

The sales agent fetches https://exa.ai/.well-known/agent-card.json, sees the list-building skill and the API-key sign-in.

2

Send the task

One SendMessage call: the task in plain text, the JSON Schema it wants back, and the effort and budget. returnImmediately lets it carry on while Exa works.

What the sales agent saved

About 2K tokens came back instead of the pages themselves. In our open test, one Exa search with page content returned 4.7K–10.6K tokens, so 15 searches would add roughly 70K–160K tokens to the agent's context (an estimate). The cost was $0.10 for a medium-effort task.

5The launch article (draft)

The post Exa could publish on launch day.

Draft launch post · written as Exa might publish it · example only

Hire Exa from any agent

Exa Agent now has a public A2A Agent Card. Any agent that speaks A2A, the open agent-to-agent protocol run by the Linux Foundation, can now find Exa, read what it can do and hand it a task. Gemini Enterprise, AWS AgentCore and Azure agents can all call it, as can your own agent.

Google answered people's queries. Exa takes agents' assignments. A search API sends back links and leaves your agent to read them, so it pays in tokens and context for every page. Exa Agent takes the whole job instead: search, read, check, and return one schema-valid JSON result with a source for every field.

What you can hire it for. The card lists four skills: research a question, build a list of companies or people, enrich rows you already have, and watch for changes. Each task has a set price, from $0.012 at minimal effort to $1.00 at xhigh, with a spending cap you control.

How it works. Your agent fetches exa.ai/.well-known/agent-card.json, sends a SendMessage request with the task and an optional JSON Schema, follows progress by streaming or polling, and receives the result as an artifact. It uses the same Exa API key, so there is nothing new to sign up for.

Why a search agent and not just a search API. Your agent's context stays small: one cited result instead of dozens of pages. Exa's own research found agents trained on Exa matched agents trained on Google results while using 69% fewer tokens. And Exa runs its own index of the web, people, companies, papers and places, so lists come back complete.
