Search API: the calling agent does the work
  1. Writes the queries, often dozens per task
  2. Gets back links and full pages (one page: 16,180 tokens as HTML, 3,150 as Markdown)
  3. Reads, filters and searches again
  4. Pays for those tokens again on every later turn
Search agent: Exa does the work
  1. Reads Exa's Agent Card to see what it can do
  2. Sends one task and an output schema
  3. Exa searches, reads and checks in its own loop
  4. Gets cited JSON back in hundreds of tokens, paid per task

The line to own
  • "Google for AI agents" is already used: a Tavily headline (Aug 2025) and Sacra on Exa (Nov 2026). Exa's own line is "The world's data for AI agents".
  • Sharper: "Google answered people's queries. Exa takes agents' assignments." A task goes in, cited JSON comes out, found through an Agent Card, paid per task, listed where enterprises buy agents.
  • Proof to pair with it: fewer tokens per correct answer, the RL study, and first search agent in the Gemini Enterprise marketplace.
